# Task 2: AI Content Marketing Using UGC Ads

## Project Overview
This project uses structured prompts to generate user-generated-content (UGC)-style advertising scripts for a product or business. The sample campaign uses a fictional skincare product concept called DewDrop Hydrating Gel.

## Objective
Generate multiple hooks, short-form ad scripts, problem-solution content, CTAs and platform-specific captions with a natural creator-style voice.

## Tools
- ChatGPT or another AI writing assistant
- Google Docs / MS Word
- GitHub
- Optional: CapCut, Runway or Canva for video production (not required for the prompt-only deliverable)

## Sample Product
DewDrop Hydrating Gel is a fictional skincare product used for demonstration. No real product claims are implied.

## Deliverables
- Product brief
- UGC ad prompt
- Multiple hooks and ad scripts
- Platform-specific captions
- CTA variations
- Prompt logic and testing documentation

## Usage
1. Replace the sample product information with verified details.
2. Paste the prompt into an AI writing tool.
3. Generate scripts and captions.
4. Review the copy for clarity, audience fit and factual accuracy.
5. Record actual testing outcomes before submitting.

## Important
Do not invent clinical claims, guaranteed results, fake testimonials, discounts or product specifications. Verify all product claims with reliable product information before publication.
